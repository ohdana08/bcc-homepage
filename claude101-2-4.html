Cowork와 Projects로 자료 묶기

반복 업무를 매번 처음부터 설명하지 않도록 프로젝트의 목적, 고정 자료, 이번 작업 자료, 출력 위치를 나눕니다. 자료를 많이 넣는 것이 아니라 필요한 맥락만 유지하는 연습입니다.

무료 · 상시 열람결과물 · 프로젝트 구조도최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

프로젝트 구조도

관련 자료와 고정 지침, 출력 위치를 하나의 업무 단위로 정리하는 프로젝트 구조 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 같은 형식의 콘텐츠를 매주 만들 때
  • 고객별 산출물을 분리해야 할 때
  • 프로젝트마다 다른 말투와 검수 기준이 필요할 때
02

실습 전 준비

  1. 가상의 ‘월간 뉴스레터’ 프로젝트를 사용합니다.
  2. 프로젝트에 넣을 자료를 고정 자료와 매회 자료로 나눕니다.
  3. Cowork Projects 기능과 저장 위치가 계정·환경에 따라 다를 수 있음을 확인합니다.
월간_뉴스레터/
├── PROJECT_GUIDE.md    목적·독자·금지사항
├── REFERENCE/          승인된 말투 예시와 형식
├── INPUT/2026-09/      이번 호 원본
└── OUTPUT/2026-09/     초안과 검수본
03

핵심 개념

프로젝트 목적 + 고정 맥락 + 이번 입력 + 출력 규칙 + 프로젝트별 기억
  • 고정 자료 · 독자, 말투, 승인된 템플릿처럼 여러 작업에 반복되는 자료입니다.
  • 이번 입력 · 이번 달 인터뷰나 공지처럼 현재 결과에만 필요한 자료입니다.
  • 프로젝트 경계 · 서로 다른 고객이나 보안 수준의 자료는 프로젝트를 분리합니다.
04

단계별 실습

1단계 · 자료를 세 종류로 분류합니다

월간 뉴스레터 프로젝트의 자료 목록을 고정 자료, 이번 호 입력, 결과물로 분류해주세요.
각 자료가 왜 필요한지와 다음 호에도 유지할지를 함께 적어주세요.

2단계 · 프로젝트 지침을 작성합니다

이 프로젝트에서 반복 사용할 지침을 작성해주세요.
독자, 목적, 문체, 기본 구조, 근거 사용 규칙, 금지 표현, 파일 이름 규칙, 최종 검수 기준을 포함하고 15줄 이내로 압축해주세요.

3단계 · 새 작업의 시작문을 만듭니다

프로젝트의 고정 지침과 이번 호 INPUT 폴더를 사용해 작업을 시작하는 짧은 요청문을 작성해주세요.
먼저 파일 목록과 부족한 자료를 보고하게 하고, 승인 전에는 초안을 쓰지 않도록 해주세요.
05

내 업무에 복사해서 쓰는 프롬프트

이 프로젝트의 새 작업을 시작합니다.

이번 목표: [완성할 결과]
이번 입력 위치: [폴더 또는 파일]
출력 위치: [폴더]

프로젝트 지침과 입력 자료를 먼저 확인하고 다음을 보고해주세요.
1. 사용할 자료 목록
2. 부족하거나 충돌하는 정보
3. 실행 순서
4. 사람이 승인할 지점
계획을 승인하기 전에는 결과 파일을 만들지 마세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 내 반복 업무 하나를 프로젝트로 가정합니다.
  2. 매번 설명하는 내용을 고정 지침으로 분리합니다.
  3. 이번에만 필요한 자료를 별도 폴더에 둡니다.
  4. 오래된 자료를 계속 유지할 이유가 있는지 검토합니다.
08

자주 생기는 오류와 주의사항

자료를 전부 넣게 됩니다

현재 결과에 영향을 주지 않는 파일은 프로젝트에서 제외합니다.

프로젝트 지침이 너무 깁니다

모든 작업에 공통인 규칙만 남기고 개별 조건은 작업 요청에 씁니다.

실제 업무에 적용하기 전에

프로젝트를 나누는 것은 접근권한을 대신하지 않습니다. 고객별·부서별 자료는 실제 권한 정책과 승인된 저장 위치에 맞춰 관리하세요.
