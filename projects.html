PROJECT 01 · WEB / DATA

315개의 후기를
탐색 가능한 신뢰 자산으로

폴더에 흩어진 이미지 후기는 많았지만 방문자가 필요한 강의의 증거를 찾기 어려웠습니다. 후기 자료를 기관·일정 기준으로 다시 구조화해 검색 가능한 게시판으로 전환했습니다.

STATUS완료 · 실제 운영 중
SCALE19개 기관 · 후기 이미지 315장
ROLE정보 구조 설계 · 개인정보 검수 · 웹 구축

문제

후기가 이미지 폴더에 쌓여 있어 강의 품질을 증명하는 공개 자산으로 활용하기 어려웠습니다.

설계와 실행

  • 기관 → 강의 일정 → 후기 구조 설계
  • 기관명·강의명 검색 적용
  • 확대 보기와 반응형 화면 구현

검증과 보호

  • 이름·프로필·이메일 모자이크
  • 공개본만 별도 관리
  • 모바일과 PC 작동 확인
증명하는 역량

비정형 자료를 정보 구조로 바꾸는 능력, 개인정보를 고려한 공개 설계, 실제 배포까지 끝내는 실행력을 보여줍니다.

STATUS공개 베타 · 개선 중
FLOW대화 → 추천 → 가입 → 진단 → 초안
ROLE서비스 기획 · 퍼널 설계 · 품질 점검

문제

사용자는 어떤 공고가 맞는지, 사업계획서를 어디서 시작할지 모르는 상태에서 긴 질문부터 마주했습니다.

핵심 판단

  • 초기 질문을 선택형으로 단순화
  • 규칙 기반 분기와 AI 역할 분리
  • 최종 보고서에 AI 사용 집중

현재 개선

STATUS강의안·교재 설계 완료
OUTPUT보고서 · 포스터 · 문서 챗봇 · 맞춤 GPT

문제

도구 기능을 많이 보여줘도 교육생이 자기 업무에 연결하지 못하면 강의가 끝난 뒤 실행이 멈춥니다.

설계 원칙

  • 기획 도우미로 개인 소재 발굴

기업·기관 강의 문의
콘텐츠 자동화

강의 메모가 글과 이미지가 되기까지

오예림 강사가 BCC 콘텐츠 제작에 사용하는 세 가지 도구입니다. 어떤 원자료를 넣고 어떤 초안을 받아 검토하는지 살펴보세요.

스레드 자동화

넣는 자료
글감이 담긴 메모와 글의 목적. 누가 읽을지, 어떤 반응을 기대하는지도 적을 수 있습니다.
나오는 결과물
같은 주제를 다른 형식으로 풀어낸 스레드 초안과 각 형식을 추천한 이유입니다. 강사가 문안을 나란히 읽고 쓸 글을 고릅니다.

블로그 자동화

넣는 자료
강의·연구 메모 원문, 또는 주제와 핵심 주장, 근거를 미리 정리한 자료입니다.
나오는 결과물
정보성 칼럼 제목과 본문 초안, 검색용 제목과 요약문, 태그가 함께 나옵니다. 강사는 본문과 검색 문구를 각각 복사해 다듬습니다.

카드뉴스 자동화

넣는 자료
글이나 참고 이미지, 카드뉴스를 만들 목적과 보여 줄 대상입니다.
나오는 결과물
장별 제목과 본문을 담은 구성표가 만들어집니다. 강사는 디자인을 고르고 카드 이미지를 미리 본 뒤 한 장씩 PNG로 저장할 수 있습니다.

초안 생성·수정은 강사의 관리자 작업실에서 진행합니다. 공개할 내용은 강사가 검토합니다.

코숏이들 뮤직비디오

오예림 강사가 제작해 유튜브 채널 ‘코숏이들’에 공개한 롱폼 세 편입니다. 보고 싶은 곡의 재생 버튼을 눌러보세요.

KOSPI Top 10 투자판

여러 화면에 흩어진 시세와 공시를 한곳에 모아 종목을 비교하는 주식 매매 검토 대시보드입니다. 프로그램이 검토할 후보를 정리하고 최종 매매 결정은 사람이 합니다.

어떤 기업을 볼까?

코스피 보통주 시가총액 상위 10개 기업을 모아 공시와 재무 상태를 확인합니다.

현재 가격은 어느 수준일까?

세 가지 시나리오로 추정한 기업 가치와 현재 주가를 나란히 비교합니다.

어떤 종목부터 살펴볼까?

조건을 통과한 기업의 거래량과 수급을 확인해 우선 검토할 후보를 최대 세 곳으로 추립니다.

PROJECT 05 · CLASS TOOL

영산대 조리학과 원가계산기

영산대학교 조리예술학과 WISE창업아카데미(2026년 12월 8일) 수업에서 쓰기 위해 만든 도구입니다. 식재료 단가와 사용량을 넣으면 1인분 원가와 판매가별 남는 금액이 바로 나옵니다.

STATUS수업 전 공개 · 12/8 수업에서 사용 예정
INPUT재료 · 산 양 · 산 값 · 쓴 양 · 손질 손실
ROLE수업 설계 · 계산 기준 정리 · 웹 구축

문제

조리 전공 학생은 만든 메뉴는 있어도 원가와 판매가를 엑셀 없이 따져 본 경험이 적습니다.

설계

  • 손질해 버리는 비율까지 반영한 원가 계산
  • 부가세 포함 여부에 따른 원가율과 남는 금액
  • 판매가를 500원씩 바꿔 보는 비교표

확인한 것

  • 손계산 대조와 입력 오류 처리 점검
  • PC·태블릿·모바일 화면 확인
  • 입력한 값은 서버로 보내지 않음
이 결과물에 대해

수업 전에 강사가 만든 도구입니다. 학생이 만든 작품이 아니며, 수업 뒤 학생이 완성한 원가표는 수업결과물에서 따로 소개합니다.
