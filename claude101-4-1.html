LEVEL 4 · 25분 실습

업무 앱과 연결하기 전 점검

앱을 연결하면 편리함과 함께 데이터 접근 범위가 커집니다. 연결 버튼을 누르기 전에 목적, 읽기·쓰기 권한, 대상 데이터, 승인자, 연결 해제 방법을 한 장으로 확인합니다.

무료 · 상시 열람결과물 · 연결·권한 검토표최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

연결·권한 검토표

Connector가 접근하거나 변경할 수 있는 범위를 확인하고 최소 권한으로 시험하는 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 메일·드라이브·메신저를 Claude와 연결하려 할 때
  • 팀에서 Connector 사용을 승인할 때
  • 연결 후 예상하지 못한 데이터 노출을 막고 싶을 때
02

실습 전 준비

  1. 실제 앱을 연결하지 않고 가상의 ‘팀 캘린더 읽기’ 사례를 사용합니다.
  2. 본인의 계정 권한이 서비스에서 그대로 적용될 수 있음을 이해합니다.
  3. 조직 관리자와 보안 담당자의 승인 절차를 확인합니다.
연결 목적: 다음 주 팀 일정 요약
대상 앱: 팀 캘린더
필요 권한: 일정 제목과 시간 읽기
불필요 권한: 일정 생성·수정·삭제, 개인 캘린더 접근
시험 계정: 가상 일정만 있는 테스트 계정
종료 후: 연결 해제와 접근 기록 확인
03

핵심 개념

명확한 목적 + 최소 데이터 + 최소 권한 + 테스트 + 해제 계획
  • 상속되는 권한 · Connector는 연결한 서비스에서 사용자가 가진 권한을 바탕으로 작동합니다.
  • 읽기와 쓰기 구분 · 조회만 필요한 업무에 생성·수정·삭제 권한을 주지 않습니다.
  • 연결 수명주기 · 연결 전 검토뿐 아니라 사용 중 점검과 종료 후 해제가 필요합니다.
04

단계별 실습

1단계 · 필요한 데이터만 적습니다

다음 주 팀 일정을 요약하기 위해 캘린더 Connector 사용을 검토합니다.
업무에 꼭 필요한 데이터와 필요하지 않은 데이터를 구분하고, 읽기·생성·수정·삭제 권한의 필요 여부를 표로 작성해주세요.

2단계 · 위험과 통제를 연결합니다

이 연결에서 생길 수 있는 위험을 잘못된 일정 접근, 개인 일정 노출, 쓰기 권한 오사용, 외부 공유로 나눠주세요.
각 위험마다 예방 통제, 발견 방법, 발생 시 중지 행동을 적어주세요.

3단계 · 연결 검토표를 완성합니다

목적, 데이터 범위, 권한, 제공자 신뢰 확인, 승인자, 테스트 방법, 결과 검수, 연결 해제 방법, 정기 재검토일이 포함된 연결 검토표를 작성해주세요. 실제 연결은 수행하지 마세요.
05

내 업무에 복사해서 쓰는 프롬프트

다음 Connector 연결을 검토해주세요.

업무 목적: [목적]
연결 서비스: [앱]
필요한 데이터: [데이터]
예상 작업: [읽기/생성/수정/삭제]
사용자와 승인자: [사람]

최소 권한 원칙으로 필요한 권한과 불필요한 권한을 구분하고, 위험·예방 통제·발견 방법·중지 행동·시험 방법·연결 해제 방법·재검토일을 포함한 검토표를 작성해주세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 현재 연결된 업무 앱 목록을 확인합니다.
  2. 최근 사용하지 않은 연결을 표시합니다.
  3. 각 연결의 쓰기 권한 필요성을 다시 검토합니다.
  4. 조직 승인 없이 연결된 업무 계정이 있다면 사용을 멈추고 담당자에게 확인합니다.
08

자주 생기는 오류와 주의사항

편의를 위해 모든 Connector를 켭니다

현재 업무에 필요한 연결 하나만 켜고 끝나면 해제 여부를 검토합니다.

읽기 전용이라고 생각했는데 변경도 가능합니다

설치 화면과 Connector 설명에서 실제 작업 권한을 확인합니다.

실제 업무에 적용하기 전에

Connector는 연결된 서비스의 데이터에 접근하거나 작업을 수행할 수 있습니다. 신뢰하는 제공자만 사용하고, 회사 계정은 조직의 승인과 관리 정책 없이 개인 Claude 계정에 연결하지 마세요.
