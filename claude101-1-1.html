Claude 첫날,
내 업무 하나를 끝내기

정리되지 않은 회의 메모를 다음 회의 전에 사용할 수 있는 업무 실행 목록으로 바꿉니다. 기능을 외우기보다 요청하고, 수정하고, 검토하는 기본 흐름을 익혀보세요.

무료 · 상시 열람결과물 · 실행 목록최종 확인 · 사람
실습 목차 완성할 것 실습 전 준비 핵심 개념 단계별 실습 복사 프롬프트 결과 검수 내 업무 미션 주의사항
01

이번 실습에서 완성할 것

업무 실행 목록

해야 할 일, 담당자, 기한, 아직 확인해야 할 내용을 한눈에 볼 수 있는 표를 만듭니다.

회의가 끝난 뒤 메모를 정리하거나, 메신저에 흩어진 요청을 목록으로 만들거나, 문서 초안을 쓰기 전에 빠진 정보를 찾을 때 사용할 수 있습니다.

02

실습 전 준비

  1. Claude 웹 또는 앱에서 새 대화를 엽니다.
  2. 아래의 연습용 회의 메모를 사용합니다.
  3. 실제 고객명, 연락처, 계약내용, 비밀번호 같은 민감정보는 입력하지 않습니다.
8월 12일 뉴스레터 발송 예정
초안 담당은 이수진, 8월 8일까지
대표 이미지는 아직 결정하지 못함
박도현이 이미지 후보를 확인하기로 함
메일 제목 후보 3개 필요
고객 명단이 최신 버전인지 확인 필요
발송 전 팀장 승인 필요
03

핵심 개념

Claude에게 일을 맡길 때는 네 가지를 함께 적습니다.

업무 + 참고자료 + 결과 형식 + 검증 기준
  • 업무 · 무엇을 해달라는 것인지 씁니다.
  • 참고자료 · Claude가 근거로 사용할 내용을 제공합니다.
  • 결과 형식 · 표, 목록, 초안처럼 원하는 모양을 지정합니다.
  • 검증 기준 · 없는 정보는 추측하지 않도록 하고 원문과 대조합니다.

처음부터 긴 프롬프트를 완성하려고 하지 마세요. 짧게 시작하고 결과를 보면서 조건을 추가하는 편이 쉽습니다.

04

단계별 실습

1단계 · 짧은 요청으로 시작합니다

아래 회의 메모를 업무 실행 목록으로 정리해주세요.

첫 결과에서 담당자가 빠진 일, 기한이 없는 일, 결정된 일과 미정인 일이 구분됐는지 확인합니다.

2단계 · 원하는 결과 형식을 추가합니다

다음 회의 전에 담당자별 할 일을 확인하려고 합니다.

표의 열을 업무, 담당자, 기한, 확정 여부로 구성해주세요.
메모에 없는 정보는 추측하지 말고 '확인 필요'라고 적어주세요.
표 아래에는 추가로 확인할 질문 3개를 적어주세요.

3단계 · 원문과 대조합니다

  1. 날짜와 이름이 원문과 같은지 확인합니다.
  2. 원문에 없는 담당자나 기한이 추가되지 않았는지 확인합니다.
  3. 미정인 대표 이미지가 확정된 것처럼 적히지 않았는지 확인합니다.
  4. 추가 질문이 실제로 부족한 정보를 묻는지 확인합니다.
05

내 업무에 복사해서 쓰는 프롬프트

아래 [자료 종류]를 [사용 목적]에 맞게 정리해주세요.

[자료 붙여넣기]

결과 형식:
- [원하는 표 또는 목록 구조]
- [길이 또는 문체]

검증 규칙:
- 자료에 없는 정보는 추측하지 말고 '확인 필요'라고 표시합니다.
- 날짜, 숫자, 이름은 원문과 대조할 수 있게 그대로 표시합니다.
- 마지막에 사람이 추가로 확인할 질문 3개를 적습니다.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 최근에 작성한 메모 중 민감정보가 없는 자료 하나를 고릅니다.
  2. 이름과 고객정보를 가상의 값으로 바꿉니다.
  3. 프롬프트의 자료 종류, 사용 목적, 결과 형식을 내 업무에 맞게 바꿉니다.
  4. 결과를 원문과 비교한 뒤 다음에도 쓸 프롬프트만 따로 저장합니다.
08

자주 생기는 오류와 주의사항

답변이 너무 일반적입니다

업무 목적과 결과 형식을 한 문장씩 추가합니다. 비슷한 예시가 있다면 개인정보를 제거한 뒤 구조만 보여주세요.

없는 담당자나 기한을 만들었습니다

자료에 없는 정보는 `확인 필요`라고 표시하도록 요청하고 최종 결과를 원문과 대조합니다.

대화가 길어지면서 답이 엉뚱해졌습니다

필요한 자료와 확정된 조건만 정리해 새 대화를 시작합니다.

실제 회사 자료를 넣기 전에

개인정보, 비밀번호, 금융정보, 건강정보, 계약상 비밀, 공개되지 않은 내부 문서는 그대로 입력하지 않습니다. 조직의 보안정책과 허용 범위를 먼저 확인하세요.
