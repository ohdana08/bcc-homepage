LEVEL 4 · 20분 실습

회사에서 개인 계정을 쓰기 전 확인할 것

개인 AI 계정으로 회사 일을 할 수 있는지는 편의가 아니라 조직 정책과 계약, 데이터 종류가 결정합니다. 허용 여부가 불분명하면 입력하지 않고 공식 계정과 담당자를 먼저 확인합니다.

무료 · 상시 열람결과물 · 안전 사용 체크리스트최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

안전 사용 체크리스트

조직 정책, 계정 구분, 민감정보, 임시 대화의 한계를 확인하는 안전 사용 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 회사 자료를 개인 Claude에 넣으려 할 때
  • 업무용 계정이 제공되지 않은 상황
  • Incognito Chat이면 안전하다고 오해하기 쉬울 때
02

실습 전 준비

  1. 실제 회사자료를 열거나 붙여넣지 않습니다.
  2. 아래 가상 업무 사례만 사용합니다.
  3. 조직의 AI·보안·개인정보 정책을 확인할 담당자를 떠올립니다.
상황: 개인 Claude 계정으로 회의록을 요약하려 함
회의록 내용: 고객 이름, 계약 금액, 출시 전 일정 포함
회사 정책: 확인하지 않음
업무용 AI 계정: 제공 여부 모름
결론을 내리기 전 질문: 누가 허용하며 어떤 자료까지 가능한가?
03

핵심 개념

조직 승인 → 승인된 계정 → 데이터 분류 → 최소화·비식별화 → 사람 검수
  • 정책 우선 · 개인 설정을 바꾸는 것보다 회사가 허용한 도구와 계정을 확인하는 것이 먼저입니다.
  • 임시 대화의 한계 · Incognito Chat은 기록과 메모리 사용 방식이 다르지만 기밀정보 입력 허가를 뜻하지 않습니다.
  • 비식별화의 한계 · 이름을 바꿔도 맥락과 숫자로 다시 알아볼 수 있다면 안전하지 않습니다.
04

단계별 실습

1단계 · 입력 전 멈춤 질문을 만듭니다

회사 업무자료를 개인 AI 계정에 입력하기 전에 확인해야 할 질문을 작성해주세요.
조직 승인, 계정 종류, 데이터 분류, 계약상 비밀, 개인정보, 보관, Connector 권한, 결과 공유를 포함하고 예/아니오로 답하게 해주세요.

2단계 · 가상 사례를 판단합니다

다음 사례를 안전 사용 체크리스트로 검토해주세요.
개인 Claude 계정, 고객 이름과 계약 금액이 포함된 회의록, 회사 정책 미확인, Incognito Chat 사용 예정.
진행/중지/담당자 확인으로 나누고, 기술 설정과 무관하게 입력하면 안 되는 이유를 설명해주세요.

3단계 · 안전한 대안을 찾습니다

원문을 개인 AI에 입력하지 않고도 업무를 진행할 대안을 제안해주세요.
회사 승인 계정 확인, 빈 템플릿 작성, 가상 데이터로 절차 시험, 내부 담당자 문의, 로컬 수작업을 우선순위대로 정리해주세요.
05

내 업무에 복사해서 쓰는 프롬프트

다음 업무자료를 AI에 입력하기 전 안전 여부를 검토해주세요. 실제 원문은 제공하지 않습니다.

자료 종류: [회의록/계약서/고객목록 등]
포함될 수 있는 정보: [정보 범주]
사용 계정: [개인/회사 승인 계정]
조직 정책 확인 여부: [확인/미확인]
연결된 앱: [없음/목록]

조직 승인, 데이터 분류, 개인정보, 계약상 비밀, 계정, 보관, Connector 권한, 외부 공유를 확인하고 진행/중지/담당자 확인으로 판단해주세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 회사 자료를 열지 않은 상태에서 정책 질문 목록을 만듭니다.
  2. 업무용 AI 계정과 승인 담당자를 확인합니다.
  3. 가상 데이터로 동일한 작업 절차를 시험합니다.
  4. 승인 범위를 문서로 확인하기 전 실제 자료를 입력하지 않습니다.
08

자주 생기는 오류와 주의사항

이름만 가리면 안전하다고 생각합니다

날짜·금액·직함·사건 조합으로 재식별될 가능성도 확인합니다.

Incognito Chat이면 무엇이든 넣어도 된다고 생각합니다

기록 방식과 조직의 입력 허가는 다른 문제입니다.

실제 업무에 적용하기 전에

Incognito Chat은 대화 기록과 메모리, 학습 사용 방식이 일반 대화와 다르지만 일정 기간 보관될 수 있습니다. 어떤 기술 설정도 회사의 보안정책과 계약상 의무를 대신하지 않습니다.
