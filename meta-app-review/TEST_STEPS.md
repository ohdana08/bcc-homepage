# Meta 검수자 단계별 테스트 방법

1. 제공된 데모 URL `/api/threads-review`를 엽니다.
2. 상단 안전 고지에서 이 데모가 읽기 전용이며 게시물·댓글·답글을 생성하지 않는다는 설명을 확인합니다.
3. **Threads로 계속**을 누릅니다.
4. Meta가 제공한 검수용 Threads 계정으로 로그인하고 요청 권한을 승인합니다.
5. 데모 화면으로 돌아오면 연결 상태가 **연결됨**인지 확인합니다.
6. 승인 권한 영역에서 `threads_basic` 및 `threads_keyword_search`가 `granted`인지 확인합니다.
7. 검색 입력란에 `AI`와 같이 공개 결과가 예상되는 키워드를 입력하고 **읽기 전용 검색**을 누릅니다.
8. 작성자, 게시물 본문, 작성 시각, 원문 링크로 구성된 결과가 최대 10건 표시되는지 확인합니다.
9. 결과가 없거나 권한이 부족하면 화면에 사람이 이해할 수 있는 오류 설명이 표시되는지 확인합니다.
10. 테스트 전체 과정에서 게시물·댓글·답글이 생성되지 않았음을 확인합니다.

## 사용 사례

운영자는 공개 게시물의 주제와 사용자 표현을 조사하여 교육 콘텐츠 기획에 참고합니다. 검색 결과는 화면에 일시적으로 표시되며, 심사용 데모는 결과를 데이터베이스에 저장하지 않습니다.
