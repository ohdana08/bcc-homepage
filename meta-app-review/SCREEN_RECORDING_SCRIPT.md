# 화면 녹화 스크립트

권장 길이: 90초 내외

1. 데모 첫 화면과 **읽기 전용 검수 데모** 제목을 보여줍니다.
2. 안전 고지를 확대하여 게시물·댓글·답글을 만들지 않는다는 문장을 읽습니다.
3. **Threads로 계속**을 누르고 OAuth 권한 화면에서 `threads_basic`, `threads_keyword_search`를 보여줍니다. 비밀번호나 토큰은 녹화에 포함하지 않습니다.
4. 승인 후 돌아온 화면에서 **연결됨**과 두 권한의 `granted` 상태를 보여줍니다.
5. 검색창에 `AI`를 입력하고 검색합니다.
6. 결과의 작성자, 본문, 시각, 원문 링크를 차례로 보여줍니다.
7. 개발자 도구 Network 탭을 열 경우 `GET /v1.0/keyword_search` 요청만 설명하고 Authorization 헤더 값은 펼치지 않습니다.
8. 마지막으로 화면의 검수 확인사항과 **POST 기반 게시·댓글 API가 없음** 문구를 보여줍니다.

내레이션 예시: “이 기능은 공개 Threads 콘텐츠를 키워드로 조회하는 읽기 전용 도구입니다. OAuth에서 승인된 권한을 확인한 뒤 keyword_search API 결과를 표시합니다. 이 심사용 경로에는 게시물이나 댓글을 만드는 기능이 없습니다.”
