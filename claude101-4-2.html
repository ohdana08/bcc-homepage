비개발자를 위한 Claude Code 첫 작업

Claude Code에 “만들어줘”라고 바로 맡기지 않습니다. 안전한 연습 폴더에서 먼저 구조를 읽게 하고, 계획을 승인한 뒤 작은 변경 하나만 수행하도록 명세합니다.

무료 · 상시 열람결과물 · 자동화 작업 명세최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

자동화 작업 명세

코딩보다 먼저 목표, 대상 폴더, 변경 금지 범위, 완료 기준을 적는 자동화 작업 명세 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 반복 파일 정리 도구의 아이디어를 설명할 때
  • 개발자에게 작은 자동화 요구사항을 전달할 때
  • Claude Code가 무엇을 바꿀지 통제하고 싶을 때
02

실습 전 준비

  1. 민감정보가 없는 새 연습 폴더를 사용합니다.
  2. 가상 업무로 ‘파일명 규칙 검사기’를 선택합니다.
  3. 기본 권한 확인 모드를 사용하고 권한 우회 설정은 사용하지 않습니다.
목표: 폴더의 PDF 파일명이 YYMMDD_주제.pdf 형식인지 검사
대상: PRACTICE_FILES 폴더만 읽기
출력: 검사 결과 report.txt
금지: 파일 이름 변경, 삭제, 이동, 외부 전송
완료: 정상/오류 파일 수와 오류 이유 표시
03

핵심 개념

목표 + 허용 범위 + 금지 범위 + 작은 단계 + 검증 + 인수인계
  • 범위 제한 · 연습 폴더 하나와 필요한 파일 형식만 대상으로 지정합니다.
  • 계획 먼저 · 코드를 쓰기 전에 현재 구조와 변경할 파일, 시험 방법을 보고하게 합니다.
  • 권한 검토 · 파일 수정과 명령 실행 요청을 읽고 필요한 행동만 승인합니다.
04

단계별 실습

1단계 · 읽기 전용으로 구조를 확인합니다

이 연습 폴더가 무엇을 위한 곳인지 파일을 읽기만 해서 설명해주세요.
파일을 만들거나 수정하거나 명령을 실행하지 말고, 현재 파일 목록과 예상되는 파일명 규칙만 보고해주세요.

2단계 · 작업 계획을 승인받습니다

PDF 파일명이 YYMMDD_주제.pdf 형식인지 검사하는 도구의 계획을 작성해주세요.
변경할 파일, 읽을 위치, 출력 파일, 검사 규칙, 테스트 사례, 실패 시 되돌리는 방법을 포함해주세요. 제가 승인하기 전에는 구현하지 마세요.

3단계 · 작은 완료 기준을 검수합니다

작업 명세가 다음 조건을 만족하는지 검토해주세요.
- 파일을 변경·삭제·이동하지 않음
- 지정한 폴더 밖을 읽지 않음
- 정상 2개와 오류 3개 테스트 포함
- report.txt만 생성
부족한 조건을 보완한 최종 명세를 작성해주세요.
05

내 업무에 복사해서 쓰는 프롬프트

다음 자동화 아이디어의 작업 명세를 먼저 작성해주세요.

목표: [무엇을 자동화]
대상 폴더: [안전한 연습 폴더]
허용 작업: [읽기/생성/수정]
금지 작업: [삭제/이동/외부 전송 등]
원하는 출력: [파일 또는 화면]
완료 기준: [확인 가능한 조건]

먼저 폴더 구조를 읽기 전용으로 확인하고, 변경할 파일·단계·테스트·실패 시 복구 방법을 계획해주세요. 제가 승인하기 전에는 구현하지 마세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 자동화하고 싶은 작은 반복 업무를 하나 적습니다.
  2. 삭제나 외부 전송이 필요 없는 첫 버전으로 줄입니다.
  3. 작업 명세만 만든 뒤 위험한 가정을 찾습니다.
  4. 구현한다면 기본 권한 모드에서 각 요청을 읽고 승인합니다.
08

자주 생기는 오류와 주의사항

처음부터 완성된 앱을 요청합니다

입력 하나와 출력 하나를 가진 작은 도구로 시작합니다.

권한 요청을 읽지 않고 승인합니다

어떤 파일과 명령이 대상인지 확인하고 예상 범위와 다르면 거절합니다.

실제 업무에 적용하기 전에

Claude Code 공식 문서는 기본 모드에서 파일 수정과 명령 실행 전에 권한을 확인하도록 안내합니다. 권한 우회 모드는 이 실습에서 사용하지 않으며, 회사 코드와 운영 환경에는 승인 없이 적용하지 않습니다.
