# 결제 고객 자료 수집서

## 수집 원칙

- 결제 확인 후에만 받는다.
- 주민등록번호, 건강정보, 계정정보, 비밀번호, 실명 고객목록은 받지 않는다.
- 고객이 이름·기관명·전화번호·이메일·거래처 등 식별정보를 임의 값으로 바꾼 샘플만 받는다.
- 전달 경로와 보관 기간은 고객에게 안내하고, 납품·수정 기간 종료 후 불필요한 원본을 삭제한다.

## 고객 질문

1. 반복업무 이름은 무엇인가요?
2. 이 업무는 매주, 매월, 비정기 중 얼마나 자주 하나요?
3. 업무를 시작할 때 받는 자료는 무엇인가요?
4. 지금은 어떤 순서로 처리하나요?
5. 최종 결과물을 누가, 어떤 목적으로 보나요?
6. 결과물은 Word, Excel, PowerPoint 중 무엇이어야 하나요?
7. 반드시 들어가야 하는 제목·열·계산·문구는 무엇인가요?
8. 절대 바꾸면 안 되는 숫자·문구·서식은 무엇인가요?
9. 지금 가장 자주 발생하는 오류나 재작업은 무엇인가요?
10. 잘 만들어졌다고 판단하는 기준 세 가지는 무엇인가요?
11. Claude, ChatGPT, Gemini 중 실제 사용할 도구와 요금제는 무엇인가요?
12. 개인정보와 기밀을 제거한 입력 샘플과 원하는 결과 샘플을 제공할 수 있나요?

## 받아야 할 파일

- 익명화한 입력 샘플 1개
- 가능하면 현재 사용 중인 결과물 샘플 1개
- 회사 서식이나 스타일 기준이 있다면 비식별화한 예시
- 계산 기준이나 용어 정의가 있다면 별도 메모

## 받지 말아야 할 것

- 실제 개인정보가 포함된 고객·직원 명단
- 비밀번호, API 키, 인증서, 로그인 쿠키
- 공개할 수 없는 계약서·재무 원장·의료 기록 원본
- 고객이 사용 권한을 갖고 있지 않은 제3자 자료

## 자료 도착 후 내부 확인

- [ ] 식별정보 제거 여부
- [ ] 한 업무·한 결과물 범위 유지 여부
- [ ] 정답 또는 수동 결과와 비교할 기준 존재 여부
- [ ] 계산·출처·누락·단정 표현 검수 가능 여부
- [ ] 사용할 AI 도구에서 실제 실행 가능한지 여부
- [ ] 5영업일 안에 납품 가능한 난이도인지 여부
