# 맞춤 AI 작업실 제작·납품 체크리스트

## 0. 시작 조건

- [ ] 외부 실결제 149,000원 확인
- [ ] 내부 테스트·0원·환불 주문이 아님을 확인
- [ ] 범위 확인서 전자 확인
- [ ] 익명화 샘플 수령
- [ ] 제작 시작 및 예상 1차 납품일 안내

## 1. 기준 결과 만들기

- [ ] 고객의 현재 수동 업무 순서를 재현
- [ ] 입력·처리·출력 경계를 한 문장으로 작성
- [ ] 결과물 필수 항목과 변경 금지 항목 표시
- [ ] 샘플의 정답 숫자·문구·출처를 기준표로 고정

## 2. AI 작업실 설계

- [ ] Claude 프로젝트·ChatGPT 프로젝트·Gemini Gem 중 실제 고객 도구 선택
- [ ] 역할, 목표, 자료 처리 순서, 금지사항, 검수 지점을 지침에 작성
- [ ] 1단계 자료 확인 프롬프트 작성
- [ ] 2단계 초안 생성 프롬프트 작성
- [ ] 3단계 검수·수정 프롬프트 작성
- [ ] AI가 확인 질문·검수 필요·도구 제한을 다르게 표시할 수 있음을 안내

## 3. 편집 파일 제작

- [ ] Word·Excel·PowerPoint 중 합의한 형식 하나로 제작
- [ ] 고객이 직접 수정할 수 있는 원본 형식인지 확인
- [ ] 원본 자료와 숫자·계산·항목을 대조
- [ ] 빈 값·중복·누락·단정 표현을 점검
- [ ] 파일명과 버전 표시

## 4. 사용 영상

- [ ] 고객의 목소리나 얼굴을 허락 없이 사용하지 않음
- [ ] 자료 위치와 시작 화면부터 초보자 속도로 보여줌
- [ ] 프롬프트를 왜 이렇게 쓰는지 쉬운 예시로 설명
- [ ] Claude는 `클로드`, Word는 `워드`로 발음 확인
- [ ] 화면 자막과 실제 클릭·입력 순서 일치
- [ ] 특정 AI 답변을 확정적으로 약속하지 않음
- [ ] 5~10분 안에 한 번 끝까지 재실행

## 5. 내부 검수

- [ ] 처음 보는 사람이 안내만 보고 실행
- [ ] 동일 샘플로 기준 결과와 비교
- [ ] 다른 익명 샘플로 두 번째 실행
- [ ] 결과가 달라졌을 때 수정 방법 포함
- [ ] 개인정보·계정정보가 산출물과 영상에 남지 않음

## 6. 납품·수정

- [ ] 납품 목록과 사용 순서 안내
- [ ] 최종 제출 전 사람의 검수가 필요하다고 고지
- [ ] 7일 수정 기한과 요청 형식 안내
- [ ] 수정 1회 반영 및 변경 내역 기록
- [ ] 고객이 두 번째 실행에 성공했는지 확인
- [ ] 성공 확인 뒤에만 사실 기반 후기 요청

## 7. 종료

- [ ] 불필요한 고객 원본과 임시파일 삭제
- [ ] 주문번호·결제금액·환불 상태 기록
- [ ] 실제 매출 스코어보드 반영
- [ ] 반복 요청이 확인된 경우에만 두 번째 업무 제안 후보로 기록
