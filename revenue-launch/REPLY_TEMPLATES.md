# 신청자 답변 템플릿

모든 문구는 외부 발송 전 대표 승인을 받는다. 이름, 업무, 결과물, 질문 부분만 실제 신청 내용으로 바꾸며 확인하지 않은 효과나 시간을 약속하지 않는다.

## 1. 적합 — 범위 확인 요청

```text
안녕하세요, [이름]님. 보내주신 내용을 확인했습니다.

이번 작업은
“[입력 자료]를 넣어 [결과물]을 반복해서 만드는 업무”
한 가지로 진행할 수 있을 것 같습니다.

제공되는 것은 맞춤 AI 지침, 3단계 프롬프트, 편집 가능한 [Word/Excel/PowerPoint] 파일 1개, 검수표, 5~10분 사용 영상입니다.
익명화 샘플을 받은 뒤 영업일 5일 안에 1차본을 드리고, 전달 후 7일 안에 수정 1회가 포함됩니다.

가격은 149,000원(VAT 포함)입니다.
사내 시스템 연동이나 다른 업무 추가는 이번 범위에 포함되지 않습니다.

제가 이해한 범위가 맞다면 “범위 확인”이라고 답해 주세요. 확인 후 결제 안내를 보내드리겠습니다.
```

## 2. 적합 — 대표 승인 후 결제 안내

```text
[이름]님, 확인 감사합니다.

결제 링크입니다.
https://bccconsulting.kr/apply.html?product=ai-workroom-pilot&utm_source=qualified_lead&utm_medium=direct&utm_campaign=workroom_pilot

결제 화면의 맞춤 제작 범위와 환불 안내를 확인해 주세요.
결제가 확인되면 개인정보와 기밀을 지운 샘플자료를 받는 방법과 일정을 영업일 기준 24시간 안에 안내드리겠습니다.
```

## 3. 추가 확인

```text
안녕하세요, [이름]님. 이 업무는 가능 여부를 정확히 보려면 세 가지만 더 확인해야 합니다.

1. 이 업무는 얼마나 자주 반복되나요?
2. 마지막에 꼭 남아야 하는 결과물은 Word, Excel, PowerPoint 중 무엇인가요?
3. 개인정보와 회사 기밀을 지운 샘플자료 1개를 제공할 수 있나요?

답변을 보고 한 가지 업무로 진행 가능한지 먼저 말씀드리겠습니다. 이 단계에서는 결제되지 않습니다.
```

## 4. 부적합

```text
안녕하세요, [이름]님. 보내주신 업무는 이번 149,000원 파일럿 범위로는 책임 있게 진행하기 어렵습니다.

이 상품은 반복업무 한 가지와 편집 파일 한 가지를 만드는 범위이며, [부적합 사유]는 포함하지 않습니다.
범위를 무리하게 약속한 뒤 결과가 달라지는 일을 피하기 위해 이번에는 결제를 권하지 않겠습니다.
```

## 5. 결제 확인

```text
[이름]님, 결제가 확인되었습니다.

이제 개인정보와 기밀을 제거한 샘플자료를 보내 주세요. 원본을 그대로 보내기 어려우면 이름·전화번호·기관명·계정정보를 임의 값으로 바꿔도 됩니다.

함께 보내실 내용:
1. 현재 업무 순서
2. 최종 결과물을 보는 사람
3. 결과물에 반드시 있어야 하는 항목
4. 절대 바꾸면 안 되는 숫자·문구·형식
5. 현재 사용 중인 AI 도구(Claude/ChatGPT/Gemini)

자료 수령과 범위 확정 후 영업일 5일 안에 1차본을 전달드리겠습니다.
```

## 6. 1차 납품

```text
[이름]님, 1차 작업실을 전달드립니다.

포함 파일:
- 맞춤 AI 지침
- 3단계 프롬프트
- 편집 가능한 [파일 형식] 결과물
- 검수 체크리스트
- 사용 영상

먼저 같은 샘플로 한 번 실행한 뒤, 다른 자료로 두 번째 실행을 해보세요.
전달일로부터 7일 안에 한 번 수정할 수 있습니다. 수정 요청은 “어느 단계에서 / 무엇이 / 기대와 어떻게 달랐는지”를 적어 보내주시면 됩니다.

AI 결과는 도구와 시점에 따라 달라질 수 있으므로 최종 제출 전 숫자·출처·누락 항목을 검수표로 확인해 주세요.
```
