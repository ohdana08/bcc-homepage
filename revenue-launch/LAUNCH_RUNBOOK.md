# 9,900원 실습팩 판매 런북

## 성공 정의

- Groble 실제 승인과 Supabase active 수강권이 일치한 외부 결제만 매출로 계산
- 내부 테스트·0원 수강권·환불 건 제외
- 누적 검증 매출 1,000,000원 이상

## 공개 전 가격 일치

세 곳이 모두 9,900원이어야 한다.

1. `claude101-pro.html` 표시 가격
2. Groble 상품 `nSq3PJ` 판매 가격
3. Supabase `products.id = 'claude101-pro'` 가격

한 곳이라도 다르면 판매를 시작하지 않는다. Groble 웹훅 금액과 Supabase 주문 금액이 다르면 수강권 생성이 거절된다.

## 배포·발송 순서

1. 코드 테스트 및 모바일 판매 페이지 확인
2. Git main 반영 및 운영 배포
3. Groble 상품명·가격을 `AI 업무 결과물 3종 실습팩 / 9,900원`으로 변경
4. Supabase 가격을 9,900원으로 변경
5. 로그인 → 결제창까지 금액 9,900원 확인
6. 카카오톡 채널 457명 메시지 설정
7. 발송비가 표시되면 대표 승인
8. 발송

## 발송 후 24시간

- 카카오 발송 성공·실패 수
- 랜딩 방문 수
- 결제 시작 수
- 검증된 외부 실결제 건수와 매출
- 로그인 오류·팝업 차단·가격 불일치 문의

## 24시간 판단

- 방문 40명 미만: 첫 두 줄·발송 시각·도달 문제 수정
- 방문 40명 이상, 결제 시작 4명 미만: 결과물과 포함 자료를 더 선명하게 설명
- 결제 시작 4명 이상, 결제 0건: 로그인·팝업·Groble 결제 마찰을 우선 점검
- 결제 1건 이상: 실제 구매 이유를 묻고 같은 이유를 2차 메시지에 반영
