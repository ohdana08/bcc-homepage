Claude와 스프레드시트 작업하기

“이 파일 분석해줘”로 시작하지 않습니다. 데이터 사전, 계산 기준, 결측값 처리, 검산 방법, 결과 형식을 먼저 정합니다. 이번 실습은 파일 생성보다 숫자를 확인할 수 있는 분석 요청서를 만드는 데 집중합니다.

무료 · 상시 열람결과물 · 데이터 분석 요청서최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

데이터 분석 요청서

데이터의 목적, 열 구조, 계산식, 가정을 먼저 적어 오류를 줄이는 분석 요청서 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 매출·문의·설문 데이터를 요약할 때
  • 반복 보고용 표와 차트가 필요할 때
  • 계산 기준이 사람마다 달라지는 것을 막을 때
02

실습 전 준비

  1. 아래 가상 CSV 구조를 사용합니다.
  2. 금액과 개인정보가 없는 연습 데이터로 진행합니다.
  3. 원본 파일은 수정하지 않고 복사본을 사용합니다.
열 이름: order_date, channel, product, quantity, unit_price, refund
행 수: 240행
기간: 2026-07-01~2026-07-31
매출 정의: quantity × unit_price
환불 처리: refund가 Y인 행은 매출에서 제외
목표: 채널별 순매출과 주문 수 비교
03

핵심 개념

분석 목적 + 데이터 사전 + 계산 정의 + 예외 처리 + 검산 + 출력 형식
  • 데이터 사전 · 각 열의 의미와 단위, 가능한 값을 먼저 설명합니다.
  • 계산 정의 · 매출이나 전환율처럼 해석이 달라지는 지표의 수식을 적습니다.
  • 검산 · 행 수, 합계, 제외 건수, 빈 값 수를 원본과 비교합니다.
04

단계별 실습

1단계 · 분석 전에 질문을 받습니다

다음 데이터 구조로 채널별 순매출과 주문 수를 분석하려고 합니다.
바로 계산하지 말고 열 의미, 매출 정의, 환불, 결측값, 중복, 날짜 범위에 대해 확인할 질문을 최대 7개 해주세요.

2단계 · 분석 요청서를 작성합니다

답변을 바탕으로 분석 요청서를 작성해주세요.
목적, 입력 데이터, 열 정의, 계산식, 제외 규칙, 결측값 처리, 출력 표, 차트, 검산 항목, 가정 목록을 포함해주세요.

3단계 · 실행 전 가정을 검사합니다

분석 요청서에서 결과를 크게 바꿀 수 있는 가정을 찾아주세요.
각 가정에 확인 방법을 붙이고, 확인되지 않은 가정은 결과에 명시하도록 검수 규칙을 추가해주세요.
05

내 업무에 복사해서 쓰는 프롬프트

다음 스프레드시트 분석을 실행하기 전에 분석 요청서를 작성해주세요.

분석 목적: [목적]
열 이름과 의미: [데이터 사전]
지표 정의와 계산식: [계산]
제외 규칙: [환불/취소/테스트 데이터]
원하는 결과: [표/차트/설명]

먼저 확인 질문을 하고, 결측값·중복·단위·날짜 범위·검산 방법·가정 목록을 포함한 요청서를 보여주세요. 승인 전에는 원본을 수정하지 마세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 민감정보가 없는 작은 표 하나를 고릅니다.
  2. 데이터 사전과 계산 정의를 적습니다.
  3. 분석 전에 가정 목록을 승인합니다.
  4. 결과 표의 합계와 행 수를 원본에서 다시 계산합니다.
08

자주 생기는 오류와 주의사항

멋진 차트는 나오지만 숫자가 다릅니다

차트 전에 제외 건수와 합계를 검산하고 계산식을 표시합니다.

원본 파일이 변경됩니다

복사본과 출력 전용 파일을 사용하고 원본 수정 금지를 요청서에 넣습니다.

실제 업무에 적용하기 전에

주민번호, 계좌번호, 연락처, 건강정보가 포함된 파일은 연습에 사용하지 않습니다. 조직이 승인한 환경과 최소한의 열만 사용하고 결과도 동일한 보안 수준으로 관리하세요.
