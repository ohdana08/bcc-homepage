LEVEL 1 · 20분 실습

좋은 답보다 좋은 작업 지시 만들기

막연한 요청을 한 번에 완벽한 프롬프트로 바꾸려 애쓰지 않습니다. Claude가 확인 질문을 하게 만들고, 그 답을 목적·자료·결과 형식·검수 기준이 담긴 업무 요청서로 정리합니다.

무료 · 상시 열람결과물 · 재사용 가능한 업무 요청서최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

재사용 가능한 업무 요청서

Claude가 먼저 필요한 정보를 묻게 한 뒤 재사용 가능한 업무 요청서를 완성하는 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 외주나 동료에게 업무를 명확히 전달할 때
  • 매주 반복하는 보고서 요청을 표준화할 때
  • 결과가 계속 엇나가는 원인을 찾을 때
02

실습 전 준비

  1. Claude에서 새 대화를 엽니다.
  2. 연습할 업무로 ‘고객 상담 후 안내메일 작성’을 사용합니다.
  3. 실제 고객 이름과 연락처 대신 가상의 정보를 사용합니다.
업무: 상담 후 안내메일 작성
대상: 무료 상담을 마친 1인 사업자
현재 아는 것: 다음 주에 다시 연락하기로 함
아직 모르는 것: 메일 길이, 강조할 혜택, 다음 행동
03

핵심 개념

초기 요청 → 확인 질문 → 답변 → 작업 지시서 → 결과 검수
  • 목적 · 누가 언제 무엇을 위해 결과물을 사용하는지 적습니다.
  • 입력 자료 · Claude가 근거로 사용할 정보와 사용하지 말아야 할 정보를 구분합니다.
  • 완료 기준 · 분량, 형식, 포함 요소, 금지 요소를 확인 가능한 문장으로 씁니다.
04

단계별 실습

1단계 · Claude에게 질문부터 맡깁니다

고객 상담 후 보낼 안내메일을 작성하려고 합니다.
바로 초안을 쓰지 말고, 좋은 결과를 만들기 위해 필요한 질문을 한 번에 하나씩 최대 5개 해주세요.
제가 답하기 어려운 질문에는 선택지 2~3개를 제시해주세요.

2단계 · 답을 업무 요청서로 묶습니다

지금까지의 답을 바탕으로 다음 항목의 업무 요청서를 작성해주세요.
- 사용 목적
- 독자
- 반드시 포함할 내용
- 제외할 내용
- 문체와 분량
- 결과 형식
- 사람이 확인할 항목
모르는 정보는 ‘확인 필요’로 표시해주세요.

3단계 · 모호한 표현을 검사합니다

이 업무 요청서에서 사람마다 다르게 해석할 수 있는 표현을 찾아주세요.
각 표현 옆에 확인 가능한 기준으로 바꾼 문장을 제안해주세요.
제가 승인하기 전에는 이메일 초안을 작성하지 마세요.
05

내 업무에 복사해서 쓰는 프롬프트

아래 업무를 수행하기 전에 결과에 영향을 주는 질문을 최대 5개 해주세요.
질문은 한 번에 하나씩 하고, 가능한 경우 선택지를 제시해주세요.

업무: [해야 할 일]
사용 상황: [누가 언제 사용하는지]
현재 자료: [제공할 자료]

질문이 끝나면 목적, 입력자료, 결과 형식, 완료 기준, 금지사항, 확인 필요 항목으로 구성된 업무 요청서를 먼저 보여주세요. 제가 승인한 뒤 결과물을 작성해주세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 이번 주 반복할 업무 하나를 고릅니다.
  2. 평소 쓰던 한 줄 요청을 그대로 적습니다.
  3. 확인 질문을 거쳐 업무 요청서로 확장합니다.
  4. 실제 결과를 검수한 뒤 다음에도 필요한 조건만 남깁니다.
08

자주 생기는 오류와 주의사항

질문이 너무 많습니다

결과에 큰 영향을 주는 질문만 최대 5개로 제한합니다.

바로 결과부터 작성합니다

“승인 전에는 초안을 작성하지 말라”는 중간 정지 조건을 추가합니다.

실제 업무에 적용하기 전에

실제 고객자료를 예시로 사용할 때는 이름, 연락처, 결제정보, 상담내용을 제거합니다. 업무 요청서 자체에도 조직의 보안 규칙을 포함하세요.
