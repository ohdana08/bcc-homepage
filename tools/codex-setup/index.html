    자주 막히는 곳

    "node" 또는 "git"을 찾을 수 없다고 나와요

    설치 직후에는 Codex가 새 프로그램을 못 찾을 수 있어요. Codex(ChatGPT 앱)를 완전히 껐다가 다시 열고, 확인 문장을 다시 보내세요. 그래도 안 되면 노트북을 재시작하세요.

    Codex가 "권한을 승인해 주세요"라고 물어봐요

    무엇을 하려는지 읽어 보고, 이 실습 폴더 안의 작업이면 승인하세요. 폴더 밖 파일 삭제나 전체 접근 허용은 거절해도 돼요.

    GitHub에 올리는데 로그인 창이 떠요

    정상이에요. 브라우저에 뜨는 GitHub 화면에서 직접 로그인하고 승인하세요. 토큰을 만들어 채팅에 붙여 넣을 필요는 없어요.

    Vercel에서 내 저장소가 안 보여요

    Import 화면의 Configure GitHub App(또는 Adjust GitHub App Permissions)을 눌러, Vercel이 볼 수 있는 저장소 목록에 실습 저장소를 추가하세요.

    Vercel 배포가 실패했어요

    Vercel의 오류 화면 글자를 복사해 Codex에 붙여 넣고 "Vercel 배포가 이렇게 실패했어. 원인 찾아서 고쳐줘"라고 하세요. 고친 뒤 다시 GitHub에 올리면 Vercel이 자동으로 다시 배포해요.
