    파일 전달이나 제작 시작이 어렵다면

    사용할 도구의 설치·로그인을 먼저 마쳐주세요. 새 작업용 폴더를 열고 받은 MD 파일을 넣은 뒤 파일 이름으로 읽어 달라고 하세요. 파일 첨부를 지원하는 화면에서는 직접 첨부해도 됩니다.

    파일을 읽지 못하면 위의 ‘내용 복사’로 업무지시서 전체를 대화에 붙여넣고 제작 시작 문장을 보내세요. 실제 입력 자료가 별도로 필요하면 함께 준비해 주세요.

    파일을 전달하는 것만으로 자동 실행되지는 않습니다. 제작 중 필요한 질문이나 실행 승인이 나올 수 있어요. 유료 연결·계정 설정·온라인 공개가 필요한지는 AI의 설명을 확인하세요.

    완성한 업무지시서를 BCC에 제출할까요?
    
      
    제출하면 BCC가 수업 결과를 관리하고 교육 개선에 활용합니다. 제출하지 않아도 위에서 파일을 받을 수 있어요.
    
      
    
      
      
    아래 사본에서 실명·연락처·기관 비밀을 지우거나 내용을 고칠 수 있어요. 위의 내 파일과 작성 기록은 그대로 유지됩니다.
    
      
      
    
      
      
    
        
        
    수집자: 비즈니스커리어컨설팅(BCC) · 목적: 수업 결과 관리·교육 개선 및 개인을 알아볼 수 없는 포트폴리오 통계. 항목: 위 업무지시서와 직접 선택한 참여 정보, 만 14세 이상 확인·동의 여부/버전/시각, 제출 확인번호. 보관: 제출일부터 3년 또는 삭제 요청 시까지. 만료 즉시 열람을 막고 매시간 정리합니다.
    
        
        
    위 항목은 제출·관리 요청 시 HTTPS로 미국의 Vercel Inc.(privacy@vercel.com) 서버를 거쳐 처리됩니다. 요청 처리 동안 사용하며 문서 본문을 별도 로그나 파일에 남기지 않습니다. 저장 DB는 Supabase의 대한민국 서울 리전이며 제출일부터 3년간 보관합니다. 동의하지 않으면 서버 제출만 이용할 수 없고, 작성·다운로드는 가능합니다.
    
        
        
    BCC가 개인정보·기관 비밀을 제거하고 검수한 일부 내용을 BCC 홈페이지 포트폴리오·강의 소개/제안 자료에 활용할 수 있습니다. 활용 기한은 최초 제출일부터 3년이며 언제든 철회할 수 있습니다. 원문을 자동 공개하지 않습니다. 동의하지 않아도 내부 제출과 도구 이용이 가능합니다.

    만든 뒤 얼마나 도움이 됐는지 남겨볼까요?
    
      
    동의하면 사용 기록 연동 설명이 담긴 업무지시서를 받을 수 있어요. AI 개발 도구가 실제로 기능을 구현한 뒤에만 기록이 들어옵니다.
    
      
    
      
    
        
        
    수집자: 비즈니스커리어컨설팅(BCC). 목적: 교육 개선·사용 결과 확인·개인을 알아볼 수 없는 포트폴리오 통계. 항목: 제출 연결번호, 무작위 실행번호, 시험/실사용 구분, 실행 시간·성공/실패·검수 상태, 입력한 경우에만 사용 전후 사람 작업시간·측정 방식·검수 항목 수와 통과 수·기준 버전, 서버 수신 시각·동의 버전/시각·전송키 해시. 업무 내용·파일·연락처는 보내지 않습니다.
    
        
    보관: 원래 업무지시서의 최초 제출일부터 3년 또는 철회·삭제 요청까지. 연동 시작으로 기한을 연장하지 않습니다. 철회하면 사용 기록을 삭제하고 수집을 차단합니다. 연결번호·철회 사실은 재수집 방지를 위해 원래 만료일까지 남습니다. 거부해도 작성·다운로드·기본 도구 사용이 가능합니다.
    
        
        
    위 항목은 도구에서 기록을 보낼 때마다 HTTPS로 미국 Vercel Inc.(privacy@vercel.com) 서버에서 검증·전송 처리되고, Supabase 대한민국 서울 DB에 원래 업무지시서의 보관 기한까지 저장됩니다. Vercel 요청 처리 동안 사용하며 기록 본문·키를 애플리케이션 로그에 남기지 않습니다. 거부하면 이 연동 기능만 제한됩니다.

    실행 시간은 사람의 업무 시간과 다릅니다. 시간 절약은 동일 업무의 사용 전후 사람 작업시간이 있을 때만, 검수 수치는 기준과 분모가 있을 때만 계산합니다. 제작 도구가 보고한 기록이며 자동으로 성과를 보증하지 않습니다.
