Claude Cowork로 반복 업무 설계하기

Cowork에 폴더를 연결하기 전에 어떤 자료를 읽고 어디에 결과를 저장할지 정합니다. 이번 실습은 실제 파일을 맡기기보다 안전한 연습 폴더와 작업 계획을 만드는 데 집중합니다.

무료 · 상시 열람결과물 · 업무 폴더 구조와 작업 계획서최종 확인 · 사람
실습 목차완성할 것실습 전 준비핵심 개념단계별 실습복사 프롬프트결과 검수내 업무 미션주의사항
01

이번 실습에서 완성할 것

업무 폴더 구조와 작업 계획서

반복 업무에 사용할 폴더 구조와 작업 순서, 사람이 확인할 지점을 먼저 설계하는 실습입니다.

이 결과물은 다음과 같은 상황에서 활용할 수 있습니다.

  • 매주 같은 보고서를 만드는 업무
  • 여러 파일을 읽고 하나의 결과물을 만드는 업무
  • 입력과 출력 파일이 자주 섞이는 업무
02

실습 전 준비

  1. 컴퓨터에 민감정보가 없는 새 연습 폴더를 만듭니다.
  2. 반복 업무로 ‘주간 업무보고 작성’을 선택합니다.
  3. Cowork 사용 가능 여부와 조직의 허용 범위를 확인합니다.
CLAUDE_PRACTICE/
├── 00_GUIDE/       업무 설명과 작성 기준
├── 10_INPUT/       이번 주 원본 자료
├── 20_OUTPUT/      Claude가 만든 결과
└── 90_TEMPLATE/    승인된 양식
03

핵심 개념

입력 폴더 + 고정 지침 + 작업 순서 + 출력 폴더 + 승인 지점
  • 폴더 경계 · Claude가 접근할 필요가 있는 연습 폴더만 연결합니다.
  • 입력과 출력 분리 · 원본을 보존하고 생성된 파일을 별도 위치에 저장합니다.
  • 사람의 승인 지점 · 외부 공유, 원본 변경, 숫자 확정 전에 사람이 멈춰 검토합니다.
04

단계별 실습

1단계 · 반복 업무를 분해합니다

매주 주간 업무보고를 만드는 일을 설계하려고 합니다.
업무를 자료 수집, 누락 확인, 초안 작성, 숫자 검증, 사람 승인, 저장 단계로 나눠주세요.
각 단계에서 필요한 입력과 만들어지는 출력을 표로 정리해주세요.

2단계 · 폴더 구조를 검토합니다

다음 연습 폴더 구조가 원본 보존과 결과 검수에 적합한지 검토해주세요.
부족한 폴더가 있다면 최소한으로 제안하고, 각 폴더에 넣으면 안 되는 자료도 적어주세요.

3단계 · 실행 전 작업 계획서를 만듭니다

지금까지 정한 내용을 Cowork 작업 계획서로 작성해주세요.
목적, 읽을 폴더, 쓰기 가능한 폴더, 작업 순서, 중간 확인 질문, 완료 기준, 사람이 승인할 지점을 포함해주세요.
아직 실제 파일은 변경하지 마세요.
05

내 업무에 복사해서 쓰는 프롬프트

다음 반복 업무를 실행하기 전에 작업 계획서부터 작성해주세요.

업무: [반복 업무]
읽을 위치: [입력 폴더]
저장 위치: [출력 폴더]
참고 기준: [가이드 또는 템플릿]

계획서에 작업 단계, 각 단계의 입력과 출력, 확인이 필요한 질문, 원본 보존 방법, 사람 승인 지점, 완료 기준을 포함해주세요. 계획을 제가 승인하기 전에는 파일을 만들거나 수정하지 마세요.
06

결과 검수 기준

아래 항목을 직접 확인하면 실습이 완료됩니다.

체크 상태는 현재 사용 중인 기기에만 저장됩니다.
07

내 업무로 바꾸는 미션

  1. 실제 반복 업무 하나를 고릅니다.
  2. 파일 이름이 아닌 입력·처리·출력 흐름을 적습니다.
  3. 민감정보가 없는 샘플 파일로 먼저 시험합니다.
  4. 결과를 확인한 뒤에만 실제 업무 적용을 검토합니다.
08

자주 생기는 오류와 주의사항

폴더 전체를 연결하려고 합니다

업무에 필요한 새 폴더만 만들고 복사본으로 시험합니다.

원본 파일이 바뀔까 걱정됩니다

출력 전용 폴더와 “원본 수정 금지” 규칙을 계획서에 명시합니다.

실제 업무에 적용하기 전에

Cowork가 접근할 수 있는 범위는 연결한 폴더와 허용한 도구에 따라 달라집니다. 회사 파일을 연결하기 전에 조직 정책을 확인하고, 첫 실습은 가상 자료와 복사본으로 진행하세요.
